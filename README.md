# 📝 Simple To-Do List App

Ek simple, responsive aur clean To-Do List web application jisme aap daily tasks manage kar sakte hain. Isme `localStorage` ka use kiya gaya hai taaki page refresh ya close hone par bhi aapke tasks save rahein.

---

## ✨ Features

- **Add Tasks:** Naye tasks quickly add karein.
- **Mark Complete:** Task par click karke use complete mark karein (strike-through effect).
- **Delete Tasks:** Kisi bhi task ko remove karne ke liye delete button.
- **Persistent Storage:** Browser ke `localStorage` mein data save rehta hai.
- **Clean UI:** Simple aur modern responsive design.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure ke liye.
- **CSS3:** Modern styling aur layout ke liye.
- **JavaScript (ES6):** Task manipulation aur LocalStorage logic ke liye.
